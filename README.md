# Modul Praktikum Pengenalan Pemrograman dengan Python

Modul praktikum untuk semester 1. Setiap modul memuat tujuan praktikum, dasar teori, contoh kode, kesalahan umum, tugas praktikum, rangkuman, dan checklist.

**Prasyarat:** Python 3.10 atau lebih baru.  
**Cara menjalankan:** simpan kode sebagai file `.py`, lalu jalankan `python nama_file.py` di terminal.

## Alur Belajar yang Disarankan

1. Baca tujuan dan prasyarat modul.
2. Ikuti dasar teori sambil mengetik ulang contoh kode.
3. Bandingkan hasil dengan blok **Output yang diharapkan**.
4. Kerjakan tugas dari tingkat dasar hingga tantangan.
5. Periksa bagian **Kesalahan Umum** jika program tidak berjalan.
