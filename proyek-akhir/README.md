# Proyek Akhir Praktikum Python

Proyek akhir terdiri atas dua tahap. Setiap tahap memiliki dua pilihan proyek, dan mahasiswa memilih **satu** proyek pada setiap tahap.

- **Tahap 1** dikerjakan setelah Modul 6 untuk menerapkan materi Modul 1–6.
- **Tahap 2** dikerjakan setelah Modul 8 untuk menerapkan materi Modul 1–8.

## Tahap 1 — Proyek Awal (Modul 1–6)

Pilih salah satu:

1. [Proyek 1 — Kalkulator Menu Interaktif](tahap-1/proyek-1-kalkulator-menu.md)
2. [Proyek 2 — Pemesanan Tiket Bioskop](tahap-1/proyek-2-tiket-bioskop.md)

### Ketentuan Tahap 1

- Bahasa pemrograman: Python 3.10 atau lebih baru.
- Program berbasis terminal/CLI.
- Kode disimpan dalam satu file utama.
- **Hanya menggunakan materi Modul 1–6.**
- Tidak menggunakan `list`, `tuple`, `dict`, atau `set`.
- Tidak menggunakan fungsi buatan sendiri (`def`).
- Gunakan `if-else`, `match-case`, `for`, dan `while` sesuai kebutuhan.
- Validasi pilihan menu, rentang nilai, dan pembagian dengan nol.
- Sertakan `README.md` berisi cara menjalankan program dan daftar fitur.

### Ketentuan Tahap 2

- Bahasa pemrograman: Python 3.10 atau lebih baru.
- Hanya menggunakan **standard library** Python. Tidak perlu memasang paket tambahan.
- Program berbasis terminal/CLI (bukan GUI atau web).
- Kode disimpan dalam satu file utama, misalnya `manajemen_nilai.py` atau `kasir_toko.py`.
- Gunakan fungsi untuk memecah program. Minimal **5 fungsi** selain `main()`.
- Gunakan struktur data yang sesuai (`list`, `dict`, atau gabungan keduanya).
- Validasi input dasar: angka tidak valid, data kosong, dan pilihan menu yang salah.
- Program harus berjalan tanpa error pada skenario normal.
- Sertakan `README.md` berisi cara menjalankan program dan daftar fitur.
- Boleh dikerjakan secara individu atau berpasangan sesuai arahan dosen.

## Deliverable

1. File Python proyek.
2. `README.md` proyek.
3. Demonstrasi singkat saat presentasi (3–5 menit).

## Tips Agar Proyek Mudah Diselesaikan

1. Mulai dari menu, lalu isi satu fitur setiap kali.
2. Uji setiap fitur dengan data kecil sebelum menambah fitur.
3. Simpan data contoh agar pengujian tidak selalu mengetik ulang.
4. Kerjakan fitur wajib terlebih dahulu, bonus setelahnya.
5. Minta teman mencoba program dan catat input aneh yang membuat program berhenti.

## Integritas Akademik

- Proyek boleh didiskusikan, tetapi kode harus ditulis dan dipahami sendiri.
- Cantumkan sumber belajar yang digunakan.
- Dosen dapat meminta penjelasan lisan atas bagian kode tertentu.
