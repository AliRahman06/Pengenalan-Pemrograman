# Kunci Jawaban Modul 1 — Pengenalan Pemrograman dan Instalasi Lingkungan Kerja

Kunci untuk tugas konseptual bersifat acuan. Jawaban mahasiswa dapat berbeda selama isinya benar.

## Tugas 1.1 — Pemrograman dan Algoritma

**Pemrograman** adalah proses menulis instruksi dalam bahasa pemrograman agar komputer dapat menjalankan tugas tertentu. Program yang ditulis harus mengikuti aturan sintaks bahasa yang digunakan.

**Algoritma** adalah urutan langkah logis dan sistematis untuk menyelesaikan suatu masalah. Algoritma tidak terikat pada bahasa pemrograman tertentu, sehingga langkah yang sama dapat diterapkan di Python, C, atau Java.

Contoh algoritma sederhana: langkah membuat teh.

1. Siapkan air, teh, gula, dan cangkir.
2. Didihkan air.
3. Masukkan teh ke dalam cangkir.
4. Tuangkan air panas.
5. Tambahkan gula sesuai selera.
6. Aduk dan teh siap disajikan.

## Tugas 1.2 — Kelebihan Python

Jawaban dapat bervariasi. Contoh jawaban yang benar:

1. **Sintaks sederhana dan mudah dibaca.** Python menggunakan struktur yang mirip bahasa Inggris sehingga cocok untuk pemula.
2. **Bersifat interpreted.** Kode dapat langsung dijalankan tanpa proses kompilasi terpisah sehingga lebih cepat diuji.
3. **Komunitas dan dokumentasi besar.** Banyak tutorial, forum, dan pustaka yang membantu ketika menemukan masalah.
4. **Digunakan di banyak bidang.** Python dipakai untuk web, data science, kecerdasan buatan, dan otomasi.

## Tugas 1.3 — Interpreter dan Compiler

| Aspek | Compiler | Interpreter |
|---|---|---|
| Cara kerja | Menerjemahkan seluruh kode sebelum dijalankan | Menerjemahkan dan menjalankan kode baris per baris |
| Contoh bahasa | C, C++, Pascal | Python, JavaScript |
| Deteksi error | Setelah seluruh kode selesai dikompilasi | Saat baris yang bermasalah dijalankan |
| Kecepatan eksekusi | Umumnya lebih cepat | Umumnya lebih lambat |
| Kemudahan pengujian | Perlu kompilasi ulang setelah perubahan | Perubahan langsung dapat dijalankan |

## Tugas 1.4 — Perbaiki Kode

Kode bermasalah:

```python
Print("Selamat belajar Python")
```

Penyebab: Python bersifat *case-sensitive*. Perintah yang benar adalah `print`, bukan `Print`. Karena `Print` tidak dikenali, muncul `NameError`.

Perbaikan:

```python
print("Selamat belajar Python")
```

Contoh output:

```text
Selamat belajar Python
```

## Tugas 1.5 — Puisi atau Pantun
